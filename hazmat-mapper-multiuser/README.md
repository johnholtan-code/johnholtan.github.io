# Hazmat Mapper (Multi-User) Scaffold

This directory is a clean scaffold for the next-generation multi-user Hazmat Mapper.

## Structure

- `client/` — front-end app shell (UI, map modules, auth, API client).
- `server/` — back-end API + real-time collaboration sockets.
- `shared/` — shared constants and type contracts between client and server.
- `docs/` — architecture, milestones, and implementation notes.
